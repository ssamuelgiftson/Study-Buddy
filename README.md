# 📚 StudyBuddy - My Personal Study Helper

> Created by **Samuel Giftson S** | Grade VIII | St Christopher Academy

## 🌟 About
StudyBuddy is a personal study companion website built to help 
with CBSE Grade VIII studies, focusing on Math, Hindi, and Science.

## 🎯 Features
- 📐 Math Formulas & Interactive Quiz
- 📝 Hindi Vocabulary Flashcards & Grammar
- 🔬 Science Quick Reference
- 🔢 Built-in Calculator
- ⏱️ Pomodoro Study Timer
- 🌙 Dark/Light Theme Toggle
- 📱 Mobile Responsive Design

## 🛠️ Built With
- HTML5
- CSS3
- JavaScript (Vanilla)

## 🌐 Live Website
[https://ssamuelgiftson.github.io/study_buddy/](https://ssamuelgiftson.github.io/study_buddy/)

## 📌 Subjects Covered
- Mathematics (Algebra, Mensuration, Geometry)
- Hindi (व्याकरण, शब्द भंडार)
- Science (Physics, Chemistry, Biology)
