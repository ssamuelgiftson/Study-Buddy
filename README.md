## 🌟 What is StudyBuddy?

**StudyBuddy** is a personal AI-powered study companion web application built for CBSE Grade VIII students. Upload your textbooks as PDFs, and StudyBuddy will help you study with real AI-generated summaries, quizzes, flashcards, and more!

> 💡 *"I built this to help myself and my classmates study smarter, not harder!"*

---

## ✨ Features

### 📤 PDF Upload & Library
- Upload any PDF textbook
- Books organized by subject with beautiful cards
- Delete books you no longer need
- Drag & drop support

### 📖 Book Reader with Real Images
- See actual textbook pages with images, diagrams & colors
- Zoom in/out for better readability
- Jump to any page instantly
- Page-by-page navigation

### 🤖 AI Study Helper (Google Gemini)
- **Real AI** powered by Google Gemini
- Summarize chapters in simple points
- Explain difficult concepts
- Generate quiz questions from any page
- Find definitions and key points
- Quick prompt buttons for common tasks
- Page-specific queries (e.g., "Summarize page 5")

### 🧠 Smart Quiz — By Chapter
- Select specific page range (chapter-wise)
- Choose number of questions (5, 10, or 15)
- Question types: Fill in Blank, True/False, Comprehension
- Explanations after each answer
- Score tracking with results

### 📐 Mathematics
- Key formulas for Grade VIII (Algebra, Mensuration, Geometry)
- Squares, cubes, exponents reference
- Profit/Loss & Interest formulas
- Interactive math quiz

### 📖 English
- Complete grammar reference (Parts of Speech, Tenses, Voice, Speech)
- Vocabulary builder with 15 words
- 🔊 **Pronunciation feature** — American 🇺🇸 & British 🇬🇧 accents
- 📖 **Built-in Dictionary** — Save learned words, search, listen anytime
- Writing tips (Letter, Essay, Notice)
- Interactive English quiz

### 📝 Hindi (हिंदी)
- Grammar: संज्ञा, सर्वनाम, विशेषण, काल
- 15 vocabulary flashcards with meanings
- Interactive Hindi quiz
- Bilingual (Hindi + English)

### 📗 Tamil (தமிழ்)
- Complete letter system (247 எழுத்துகள்)
- Grammar: பெயர்ச்சொல், வினைச்சொல், காலம், வேற்றுமை
- **40 vocabulary flashcards** with English meanings
- 15 quiz questions
- 6 famous Tamil proverbs with translations

### 🔬 Science
- Physics formulas (Force, Pressure, Speed, Work)
- Chemistry concepts (Atoms, pH Scale, Combustion)
- Biology basics (Cell, Nucleus, Mitochondria)
- Environmental science

### 🔤 Book Flashcards
- Auto-generated from uploaded book content
- Key terms extracted intelligently
- Flip animation

### 📝 Notes
- Create, edit & delete study notes
- Organized and searchable
- Saved permanently

### ⏱️ Pomodoro Timer
- Study timer with preset options (25m, 5m, 15m, 45m)
- Beautiful gradient display

### 🌙 Dark Mode
- Toggle between light and dark themes
- Preference saved automatically

### 👋 Personalized Greeting
- Time-based greeting (Morning/Afternoon/Evening/Night)
- Motivational study messages

## 🔧 Setup & Usage

### For Users:
1. Visit the [live website](https://ssamuelgiftson.github.io/study_buddy/)
2. Enter your name
3. Upload your PDF textbooks
4. Start studying! 🎉

### For AI Features:
1. Get a free API key from [Google AI Studio](https://aistudio.google.com/apikey)
2. Go to 🤖 AI Help section
3. Paste your API key (saved locally, never shared)
4. Select a book and start asking!
